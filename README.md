# To-Do List

A small browser-based To-Do app built with ES modules. Tasks are saved in
`localStorage`; malformed or unavailable stored data is handled safely.

## Requirements

Use Node.js 22 or 24. Install dependencies with `npm install`, then start the
development server with `npm run dev`.

Run the test suite with `npm test`, check style with `npm run lint`, and create a
production build with `npm run build`.
